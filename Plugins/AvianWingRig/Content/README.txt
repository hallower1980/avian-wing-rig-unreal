AvianWingRig Content
====================

This plugin ships source + docs, not binary Control Rig .uasset files.

Suggested project content (create in your game project after enabling the plugin):

  /Game/AvianWingRig/DA_AWR_Magpie          — UAvianWingPresetDataAsset (Tools menu or Python)
  /Game/AvianWingRig/CR_AvianWing           — your Control Rig (see docs/CONTROL_RIG.md)
  /Game/AvianWingRig/ABP_Bird               — AnimBP hosting the Control Rig node

Python helpers live in Content/Python/ (Editor Python Plugin).
